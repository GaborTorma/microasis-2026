# Manas 2026 — Apple apps (iOS + watchOS)

Unofficial native companion apps for the Manas 2026 festival. Both apps consume
the **same Neon-backed JSON API** as the PWA (`https://manas2026.vercel.app/api`)
— no separate backend.

## Layout

```
apple/
  project.yml                 # XcodeGen project definition (source of truth)
  Sources/
    ManasKit/                 # shared, platform-agnostic code
      Models.swift            #   Codable DTOs (matches the web API)
      APIClient.swift         #   async fetch + offline disk cache
      AppState.swift          #   ScheduleStore + Settings (order/hidden/locale)
      Localization.swift      #   AppLocale (HU default) + UI strings
      Formatting.swift        #   Europe/Budapest date/time formatting
      Theme.swift             #   green palette + Color(hex:) + language chips
    Manas-iOS/                # iOS / iPadOS app (SwiftUI)
      ManasApp.swift, RootView.swift, TimetableView.swift,
      NowView.swift, SettingsView.swift
    Manas-watch/              # watchOS app (SwiftUI)
      ManasWatchApp.swift, WatchRootView.swift, WatchSettingsView.swift
    Manas-watch-widget/       # watchOS WidgetKit extension (embedded in the watch app)
      ManasWidgetBundle.swift #   @main bundle (now-playing + launcher)
      NowWidget.swift         #   configurable 3×1 now-playing (.accessoryRectangular)
      StageSelection.swift    #   stage AppEntity/query + WidgetConfigurationIntent
      LaunchWidget.swift      #   tiny launcher (circular / inline / corner)
```

`ManasKit` sources are compiled into **both** app targets (no separate module),
so the files do not `import ManasKit`.

## Build & run

Requires Xcode 16+ (developed against Xcode 26.5).

```bash
brew install xcodegen          # one-time, if needed
cd apple
xcodegen generate              # creates Manas.xcodeproj from project.yml
open Manas.xcodeproj           # then pick the Manas (iOS) or ManasWatch scheme
```

Headless build (no signing needed for the simulator):

```bash
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
xcodebuild -project Manas.xcodeproj -scheme Manas \
  -destination 'platform=iOS Simulator,name=iPhone 17' build CODE_SIGNING_ALLOWED=NO
xcodebuild -project Manas.xcodeproj -scheme ManasWatch \
  -destination 'platform=watchOS Simulator,name=Apple Watch Series 11 (46mm)' build CODE_SIGNING_ALLOWED=NO
```

> `Manas.xcodeproj` and the generated `Info.plist` files are git-ignored — they
> are regenerated by `xcodegen generate`. Commit `project.yml` + `Sources/`.

## Features

**iOS / iPadOS** — green theme matching the PWA:
- Continuous, time-proportional **timetable** (per-day): fixed hour gutter,
  horizontally scrollable stage columns, language chips on workshops, live
  "now" line.
- **Now** tab: per-stage now-playing + up-next, with a pre-festival countdown.
- **Settings**: drag to reorder stages, eye toggle to hide them.
- HU/EN toggle (HU default). Map view is intentionally omitted (paused on web too).

**watchOS** — one stage at a time, no time grid:
- Card shows **stage name · date · time-range · act name** (+ language chip).
- **Swipe up/down** → previous/next act on the current stage.
- **Swipe left/right** → switch stage, keeping the same point in time.
- Settings (⚙) to reorder / hide stages. Defaults to the festival's default
  stage and the act on now.

**watchOS widgets** (Smart Stack + watch-face complications):
- **Now playing** (`.accessoryRectangular`, 3×1): stage name top-left, time
  range top-right, act name full-width below. **Configurable** — pin each
  instance to a stage, then add one per stage to the Smart Stack and turn the
  crown to page between them (the swipe-style navigation lives in the app; the
  Smart Stack scroll is the watch-widget equivalent).
- **Launcher** (`.accessoryCircular` / `.inline` / `.corner`): a tap opens the app.
- The extension reads the schedule cache it shares with the watch app (App
  Group `group.ai.torma.manas.2026`; a copy fresher than 6 h skips the network,
  otherwise it does its own ETag-revalidated fetch) and follows the watch app's
  language via the same App Group (device language until the app sets one).
  Each timeline entry sits on an act boundary, so the widget rolls onto the
  next act on time without extra fetches.

Each device keeps its own settings (the apps are independent — no pairing
required). Schedule is cached on disk for offline use.
